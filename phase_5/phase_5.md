# Фаза 5. Планирование

## Задание
- Возьмите проект (из 1 и 3 фазы), разложите его выполнение на отдельные задачи (подробно не декомпозируйте, задачек 20-25 в самый раз).
- На основе соображений, сделанных на 3 фазе, укажите необходимый для его реализации состав команды с делением на специальности (разработчик, тестировщик, дизайнер, …). Это будут имеющиеся в вашем распоряжении человеческие (неисчерпаемые) ресурсы. Специализации - типы ресурсов.
- Для каждой задачи укажите ресурсные требования (сколько нужно людей и каких специальностей).
- Укажите связи предшествования между задачами.
- Пользуясь предоставленным в помощь кодом, решите задачу простыми эвристическими методами (переберите различные эвристики, добавьте к ним некоторое число случайно сгенерированных, возьмите лучшее за итоговое решение). Возможные эвристики упорядочения работ:
    - **SLK** - по возрастанию общего резерва $LST_j - EST_j$;
    - **FREE** - по возрастанию свободного резерва = $min(EST_i \forall i \in IS_j) - EFT_j$;
    - **LST** - по возрастанию позднего времени начала;
    - **LFT** - по возрастанию позднего времени завершения;
    - **LSTLFT** - по возрастанию суммы позднего начала и позднего завершения = $LST_j + LFT_j$;
    - **GRPW** - по убыванию суммарной длительности задачи и её прямых последователей = $d_j + (\sum d_i \forall i \in IS_j)$;
    - **LPT** - по убыванию длительности;
    - **MIS** - по убыванию числа прямых последователей;
    - **GRD** - по убыванию произведения длительности и суммарных затрат неисчерпаемых ресурсов $d_j (\sum r_{jk})$;
    - **GRWC** - по убыванию суммарных затрат неисчерпаемых ресурсов;
    - **GCRWC** - по убыванию суммарных затрат неисчерпаемых ресурсов работы и её прямых последователей;
    - **ROT** - по убыванию суммы отношений затрат неисчерпаемых ресурсов каждого вида к их запасам, делённой на продолжительность работы = $\frac{\sum_{k=1}^{K\rho} \frac{r^{\rho}_{ik}}{R^{\rho}_k}}{d_i}$.
- “Натяните решение” на обычный 8-часовой рабочий график (40 часовая рабочая неделя) и определите плановые сроки выполнения проекта и отдельных этапов.

## Определение задач
Проект, подробно описанный в [фазе 3](.phase_3./phase_3.md), необходимо разделить на задачи.

1. Реализовать экран регистрации и входа в игру.
   - Экран ввода email и пароля.
   - Проверка формата email и требований к паролю.
   - Отображение сообщений об ошибках входа или регистрации.
2. Реализовать серверную логику регистрации и авторизации.
   - Создание аккаунта пользователя.
   - Проверка уникальности email.
   - Хэширование и хранение паролей.
   - Авторизация пользователя и выдача сессии.
3. Реализовать сервис подтверждения email.
   - Генерация кода подтверждения.
   - Отправка кода на email пользователя.
   - Проверка корректности введённого кода.
   - Активация аккаунта после подтверждения.
4. Реализовать ввод и сохранение имени персонажа.
   - Экран ввода имени персонажа после регистрации.
   - Проверка корректности имени.
   - Сохранение имени в профиле игрока.
5. Реализовать экран создания персонажа.
   - Выбор базовых параметров персонажа (пол, стартовый образ).
   - Отображение предварительного результата.
   - Подтверждение создания персонажа.
6. Реализовать создание стартового состояния новой игры.
   - Создание сущности персонажа.
   - Инициализация стартовых характеристик.
   - Создание первой игровой сессии.
7. Реализовать систему локаций.
   - Загрузка данных локации.
   - Хранение информации о текущей локации игрока.
   - Подготовка структуры для добавления новых локаций.
8. Реализовать перемещение персонажа по локации.
   - Управление перемещением персонажа.
   - Ограничение перемещения границами локации.
   - Обновление позиции персонажа.
9. Реализовать систему интерактивных объектов.
   - Определение интерактивных объектов на локации.
   - Возможность взаимодействия с объектами.
   - Обработка игровых триггеров.
10. Реализовать систему NPC.
    - Размещение NPC на локациях.
    - Определение зон взаимодействия с NPC.
    - Обработка начала взаимодействия.
11. Реализовать диалоговую систему.
    - Отображение реплик NPC.
    - Выбор вариантов ответа игроком.
    - Ветвление диалога в зависимости от выбора.
12. Реализовать журнал квестов.
    - Отображение списка активных квестов.
    - Отображение выполненных квестов.
    - Хранение состояния квестов.
13. Реализовать механизм выдачи квестов
    - Получение квеста от NPC или интерактивного объекта.
    - Добавление квеста в журнал.
    - Проверка условий доступности квеста.
14. Реализовать логику выполнения и завершения квестов.
    - Отслеживание прогресса выполнения квеста.
    - Проверка условий завершения.
    - Изменение статуса квеста.
15. Реализовать систему наград за квесты.
    - Начисление опыта персонажу.
    - Выдача предметов или других наград.
    - Обновление состояния персонажа после награды.
16. Реализовать систему инвентаря.
    - Отображение списка предметов.
    - Проверка формата email и требований к паролю.
    - Отображение сообщений об ошибках входа или регистрации.
17. Реализовать систему игровых предметов.
    - Определение типов предметов.
    - Описание эффектов предметов.
    - Связь предметов с квестами и боем.
18. Реализовать боевую систему.
    - Инициация боя с противником.
    - Выбор действий игрока.
    - Расчёт результата боя.
    - Завершение боя.
19. Реализовать систему развития персонажа.
    - Начисление опыта за действия.
    - Повышение уровня персонажа.
    - Улучшение характеристик.
20. Реализовать сохранение игрового прогресса.
    - Ручное сохранение состояния игры.
    - Автоматическое сохранение в контрольных точках.
    - Хранение данных сохранения.
21. Реализовать загрузку сохранённой игры.
    - Выбор сохранённого состояния.
    - Восстановление состояния персонажа и мира.
    - Возобновление игровой сессии.
22. Реализовать систему лора и сюжетных записей.
    - Хранение открытых записей лора.
    - Просмотр лора игроком.
    - Связь лора с квестами и событиями.
23. Реализовать главное меню игры.
    - Экран начала новой игры.
    - Экран загрузки сохранения.
    - Выход из игры.
24. Реализовать систему логирования игровых событий.
    - Логирование ключевых действий игрока.
    - Использование логов для отладки и тестирования.
